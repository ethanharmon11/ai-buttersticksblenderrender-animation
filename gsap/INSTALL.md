# Butter Sticks Golf — website intro install

## The file

**`intro_fade_color_embed.html`** — the colored lining intro (badge pattern in
brand color behind the copper wordmark).

It is fully self-contained: GSAP and all artwork are inlined, no external
requests, no build step, ~157 KB. Upload it anywhere on the site, e.g.
`/intro/intro_fade_color_embed.html`.

The tone-on-tone version is `intro_fade_embed.html` — identical behavior, so
everything below applies to either file.

## What the embed does

- Plays once, ~5 seconds.
- Click anywhere skips to the end.
- On finish it fades itself out and posts `bsg-intro-done` to the parent page.

## Paste into the site

```html
<div id="bsg-intro" style="position:fixed; inset:0; z-index:9999; background:#EADDC1;">
  <iframe src="/intro/intro_fade_color_embed.html"
          title="Butter Sticks Golf"
          style="width:100%; height:100%; border:0; display:block;"></iframe>
</div>

<script>
  (function () {
    var overlay = document.getElementById("bsg-intro");
    if (!overlay) return;

    // Play once per visitor. Delete this block to play on every visit.
    if (sessionStorage.getItem("bsgIntroSeen")) {
      overlay.remove();
      return;
    }

    function dismiss() {
      sessionStorage.setItem("bsgIntroSeen", "1");
      overlay.style.transition = "opacity .4s";
      overlay.style.opacity = "0";
      setTimeout(function () { overlay.remove(); }, 450);
    }

    window.addEventListener("message", function (e) {
      if (e.data === "bsg-intro-done") dismiss();
    });

    // Safety net: never trap the visitor if the iframe fails to load.
    setTimeout(dismiss, 9000);
  })();
</script>
```

Notes:

- The overlay background is set to the intro's cream `#EADDC1` so there is no
  flash of white before the iframe paints.
- `sessionStorage` shows the intro once per browser session. Use
  `localStorage` instead to show it once ever, or drop that block to play on
  every page load.
- The 9-second timeout is a safety net only — normal completion arrives via
  the `bsg-intro-done` message at ~5s.

## Changing the look

Both variants are generated by `tools/build_fade_intro.py`; edit and re-run it
rather than hand-editing the HTML. The two knobs at the bottom of that file:

```python
emit("intro_fade",       build(colored=False, lining_opacity=0.15))
emit("intro_fade_color", build(colored=True,  lining_opacity=0.30))
```

`lining_opacity` is how strongly the pattern reads. Above ~0.40 it starts
competing with the wordmark.
